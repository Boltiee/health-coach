# Commit and Push to GitHub

Stage all changes, create a commit with a descriptive message that summarises the changes, and push to the main branch on GitHub.

Steps:
1. Check git status to see what has changed
2. Stage all changes (or ask which files to stage)
3. Generate or ask for a commit message that describes the changes
4. Commit the changes
5. Push to origin/main on GitHub

Make sure to:
- Write clear, concise commit messages
- Verify there are changes to commit
- Confirm push was successful
- Request git_write permissions when needed
